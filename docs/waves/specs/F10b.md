# F10b Consultation de paire optionnelle et outils d'exploitation

## Summary

Deux fonctions sensibles de l'administration : la consultation d'une paire, désactivée par défaut, qui exige la ressaisie du mot de passe, porte sur une personne à la fois et est tracée pour tous les participants ; et les outils d'exploitation qui manipulent des données personnelles (export et import JSON des participants, sauvegarde SQLite, réinitialisation d'accès, duplication d'un groupe pour l'année suivante, suppression avec purge).

## In scope

- Option de groupe « l'administrateur peut consulter une paire » (désactivée par défaut) : consultation par personne après ressaisie du mot de passe d'administration, jamais de tableau complet, consignée dans un journal visible de tous les participants (« l'organisateur a consulté une paire le … », sans nom, sans courriel envoyé à tous). Quand l'option est désactivée, aucune route de consultation n'existe.
- Export et import JSON des participants : le format et le service sont ici ; l'import valide strictement le schéma, nettoie les saisies, applique les mêmes règles d'unicité que F3 (`NormalizeName`, `NameExists`) et, en cas d'erreur, n'importe rien (transaction). L'écran est dans la section « Données » des réglages de F10.
- Outils d'exploitation : export et import JSON des participants (via F3), sauvegarde SQLite téléchargeable (copie cohérente, par exemple `VACUUM INTO`), réinitialisation d'accès administrateur avec mot de passe généré affiché une seule fois (via F2), duplication d'un groupe pour l'année suivante (participants, foyers, exclusions, réglages ; sans tirage ni lettres), suppression de groupe avec purge optionnelle (confirmation intégrée, jamais de boîte du navigateur).
- Le format JSON des participants inclut le rôle dans le tirage (`draw_role`) : à l'import une valeur absente vaut `normal` (anciens exports), une valeur inconnue fait refuser tout le fichier (import atomique) ; l'export écrit le rôle ; la duplication d'un groupe pour l'année suivante conserve les rôles.
- Internationalisation (F13) : aucun texte brut dans les gabarits, les messages ni les courriels de cette fonctionnalité ; tous passent par les fonctions `t` et `tn` avec des clés préfixées par le module dans `web/static/i18n/<module>/fr.json` et `en.json` (français et anglais, mêmes clés, mêmes paramètres). Les textes affichés par du JavaScript sont fournis par le gabarit en attributs `data-*` produits avec `t`, jamais écrits en dur dans le script.
- Contraintes web héritées de F2c : tout gestionnaire qui modifie l'état est enveloppé par `websec.RequireUnsafeMethod` (une requête GET ne modifie jamais rien) ; aucune page n'utilise d'attribut `style` en ligne ni de ressource `data:` (CSP stricte : classes et CSS dans `web/static/css/**`, images servies par une route de même origine).

## Out of scope

- Pages principales d'administration (F10), règles d'unicité (F3).

## Steps

- F10b.1 Option de consultation de paire : ressaisie du mot de passe, une personne à la fois, journal visible de tous les participants, route absente quand l'option est désactivée.
- F10b.2 Outils d'exploitation : export et import JSON atomiques, sauvegarde SQLite cohérente, réinitialisation d'accès, duplication de groupe et suppression avec purge optionnelle.
- F10b.3 Rôle dans le tirage dans l'export et l'import JSON atomiques et dans la duplication de groupe.
