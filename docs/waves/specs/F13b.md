# F13b Relecture et contrôle de qualité des textes anglais

## Summary

Les textes anglais écrits fonctionnalité par fonctionnalité sont relus d'un seul tenant avant la recette : mêmes termes pour les mêmes notions dans toutes les pages et tous les courriels, ton chaleureux et clair, aucun reste de français, objets de courriels sobres. Cette fonctionnalité corrige les catalogues anglais et ajoute des tests de qualité qui empêchent les régressions.

## In scope

- Relecture et correction de tous les fichiers `web/static/i18n/**/en.json` : glossaire cohérent (par exemple « draw », « gift », « letter to Santa », « organiser »), phrases naturelles, pluriels `.one` et `.other` complets, paramètres inchangés.
- Tests de qualité (`internal/i18n/review/`) : aucun mot-outil français courant dans une valeur anglaise (liste documentée), aucune valeur anglaise longue identique à la française, pluriels anglais complets, objets des courriels anglais de 60 caractères au plus sans capitales intégrales ni « !!! ».
- La commande `secretsanta i18n check en` sort avec le code 0.

## Out of scope

- Ajout de nouvelles clés ou de nouvelles fonctionnalités, relecture du français, autres langues.

## Acceptance criteria

```yaml criteria
AC1: {text: "Aucune valeur anglaise ne contient de mot-outil français courant (liste documentée), aucune valeur anglaise de plus de trois mots n'est identique à la valeur française et chaque pluriel anglais a les formes one et other", verify: "test:internal/i18n/review/english_quality_test.go"}
AC2: {text: "Les objets des courriels anglais font 60 caractères au plus, sans capitales intégrales ni suite de points d'exclamation", verify: "test:internal/i18n/review/english_mail_subjects_test.go"}
AC3: {text: "La commande secretsanta i18n check en sort avec le code 0 sur les catalogues anglais embarqués", verify: "cmd:go run ./cmd/secretsanta i18n check en"}
```

## Steps

- F13b.1 Relire et corriger les catalogues anglais de toutes les fonctionnalités et écrire les tests de qualité de l'anglais.
