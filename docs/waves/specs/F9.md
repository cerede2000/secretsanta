# F9 Thème de Noël, illustrations, avatars et application installable

## Summary

Cette fonctionnalité donne à l'application son identité festive : thème de Noël (rouge, vert sapin, or, dégradé bleu nuit, fond givre menthe), neige légère, illustrations SVG originales, police manuscrite locale, avatars festifs, manifeste web et service worker minimal. Rien ne dépend d'une ressource externe, ni framework ni étape de build.

## In scope

- Thème : variables de couleur CSS rouge #c41e3a, vert sapin #165b33, or #ffd700, dégradé bleu nuit (`web/static/css/theme/`) ; contrastes de texte conformes (AA) ; composants de base mobile d'abord (boutons de 44 px minimum, aucun débordement horizontal dès 360 px).
- Fond clair : « givre menthe » #eaf4ee avec cartes blanches et flocon décoratif doré (choix de l'utilisateur) ; la fiche `tokens` de la maquette approuvée fait foi pour toutes les valeurs. Les écrans de l'inscription par lien (F11) consomment ce même thème : il n'y a rien d'autre à livrer ici pour eux.
- Neige animée en CSS léger, coupée par prefers-reduced-motion ; un petit module JavaScript natif (`web/static/js/theme/`) peut seulement l'activer, sans animation par flocon en JavaScript ; coût limité (nombre de flocons borné).
- Illustrations SVG originales dessinées dans le projet (`web/static/assets/`) : renne, lutin, sapin, Père Noël, boîte aux lettres, cadeaux, guirlandes. Aucune ressource externe : ni police, ni image, ni script, ni feuille de style distants.
- Police manuscrite embarquée localement (fichier de police sous licence libre, licence versionnée dans le dépôt) avec repli système.
- Avatars festifs calculés en local, choisis de façon déterministe par hash du prénom (module JavaScript natif, aucun service externe).
- Application installable : manifeste web (`web/static/manifest.webmanifest` : nom, icônes, couleurs, affichage autonome), icônes générées ; un service worker minimal (`web/static/sw.js`) si nécessaire à l'installation, sans mise en cache de données personnelles ni de réponses dynamiques du serveur. Les balises du manifeste dans `web/templates/layout/` et la route servant le service worker à la racine sont à brancher par l'orchestrateur.
- À brancher par l'orchestrateur : balises du manifeste dans `web/templates/layout/`, route du service worker à la racine, textes dans les catalogues `web/static/i18n/<module>/fr.json` et `en.json` (français et anglais, un dossier par module, propriété de la phase concernée).

## Out of scope

- Animation de découverte (F9c), carte statique de cible (F4d), pages propres aux autres fonctionnalités (elles consomment le thème).
